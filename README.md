# Task - Structured Output

## Project Description
This project demonstrates structured AI output validation using Pydantic.

## Features
- Student data validation
- Age validation (1 to 100)
- Invalid response handling
- Retry mechanism (3 attempts)
- JSON output generation
- Unit testing using pytest

## Technologies
- Python
- Pydantic
- Pytest

## Installation

```bash
pip install -r requirements.txt
```

## Run the project

```bash
python main.py
```

## Run tests

```bash
python -m pytest -v test_main.py
```
